⚠️ Motor Not Spinning? Check List

  • RESET ↔ SLEEP: Jumper wire MUST connect RESET directly to SLEEP. If missing, driver stays in sleep mode!
  • Holding Torque: Type ENABLE. If shaft turns freely, no coil power is reaching the motor.
  • VREF Tuning: Multimeter on trimpot screw must measure 0.12V (120 mV). If 0V, current is shut off.
  • Slow Speed Test: SPEED 100 then STEP 500.

ℹ️ One Firmware, Two Modes

stepper_motor_test.ino is unified for both Single and Dual test modes.

  • Single Motor: Wire Motor A only. Run STEP, SPEED, BACKLASH.
  • Dual Motor: Add Motor B. Run DUAL STEP, DUAL CIRCLE.

⚡ Capacitor Selection

Your stock: 47 µF (16V), 470 µF (25V), 1000 µF (25V).

Use the 470 µF 25V!

Minus (−) band to GND rail, (+) long leg to VMOT rail. Keep within 1–2 cm of A4988 pins.
