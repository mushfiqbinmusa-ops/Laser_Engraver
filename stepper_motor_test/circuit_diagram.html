stepper_motor_test.ino is a unified test suite for both Single and Dual stepper testing.

  • Single Motor: Wire only Motor A. Run STEP, SPEED, BACKLASH, STALL.
  • Dual Motor: Add Motor B later. Run DUAL STEP, DUAL CIRCLE, DUAL GOTO.

⚡ Capacitor Guide

Your stock: 47 µF (16 V), 470 µF (25 V), 1000 µF (25 V).

Use the 470 µF 25 V!

4.7× better than 100 µF. Absorbs inductive back-EMF spikes, protecting A4988 FETs. Place within 1–2 cm of VMOT/GND.
