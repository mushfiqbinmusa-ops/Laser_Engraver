Why Only 1 Test Firmware File?

Yes! stepper_motor_test.ino is an ALL-IN-ONE unified test suite for both Single Stepper and Dual Stepper bench testing.

  • Single Motor Mode: When only Motor A is wired, Motor B's pins remain disabled. Run commands like STEP 2048, SPEED 800, BACKLASH without errors.
  • Dual Motor Mode: Wire Motor B when ready. Run coordinated vector commands: DUAL GOTO 2000 2000, DUAL CIRCLE 1500.

Capacitor Selection Guide

Your Capacitors: 47µF (16V), 470µF (25V), 1000µF (25V).

Recommendation: Use the 470µF 25V!

It is even better and safer than a 100µF capacitor! It absorbs inductive Back-EMF spikes when coils switch, shielding the A4988 FETs from voltage blowouts.
