⚠️ Sensor Stuck DETECTED / CLEAR?

  • Always DETECTED: turn the blue trim-pot COUNTER-CLOCKWISE until the green LED turns OFF.
  • Always CLEAR: VCC must be on the 5V pin (not 3.3V), then turn trim-pot CLOCKWISE.
  • Emitter crosstalk: straighten the clear/dark LEDs parallel; tape between them if needed.
  • Run THRESHOLD for live diagnosis.

ℹ️ Why Direct 5V Is Safe

The ESP32-S3 GPIO tolerates max 3.6V. The onboard green LED + ~1kΩ sit between VCC (5V) and OUT, so the LED forward drop (≈2.0–2.2V) limits OUT to ~2.8–3.2V when clear — perfectly safe.

Measured clear level: < 3.3V

Only add the divider if a clone sensor reads > 3.3V.

🔧 Optional Divider (Clones)

OUT ──[10kΩ]──┬──► GPIO 3 / 8
             │
           [20kΩ]
             │
            GND

Result: 5V × 20k/(10k+20k) = 3.33V max at the GPIO.
